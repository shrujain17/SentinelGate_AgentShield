Project Abstract

A simple overview of the problem AgentShield addresses and the approach it takes.

AgentShield is an AI security gateway designed to protect AI agents from malicious instructions hidden in documents. It scans uploaded PDF, DOCX, TXT, and CSV files to detect threats such as prompt injection, data theft, and unauthorized actions. Based on its analysis, the system allows, flags for review, or blocks suspicious content before it reaches the AI agent. Its Security Operations Center (SOC) dashboard helps users monitor threats, review security decisions, and track activity. The goal is to make AI systems safer, more reliable, and more secure.
